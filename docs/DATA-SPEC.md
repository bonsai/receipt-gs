# Data Specification

## 1. Quiz JSON
Path: `public/data/sample-quiz.json`

```json
{
  "quizId": "sample-001",
  "title": "AI Receipt Quiz",
  "version": 1,
  "settings": {
    "questionCount": 5,
    "showExplanation": true,
    "shuffleChoices": false
  },
  "questions": [
    {
      "id": "q001",
      "type": "single-choice",
      "question": "What does 3DGS stand for?",
      "choices": [
        { "id": "a", "text": "3D Gaussian Splatting" },
        { "id": "b", "text": "3D Graphic System" },
        { "id": "c", "text": "3D Geometry Shader" }
      ],
      "correctChoiceId": "a",
      "explanation": "3D Gaussian Splatting represents a scene using Gaussian primitives.",
      "print": {
        "questionDelayMs": 35,
        "choiceDelayMs": 25
      }
    }
  ]
}
```

## 2. Field definitions
| Field | Type | Meaning |
|---|---|---|
| quizId | string | Stable quiz identifier |
| title | string | Display title |
| version | integer | Schema version |
| questionCount | integer | Intended number of questions |
| showExplanation | boolean | Whether to print explanation |
| shuffleChoices | boolean | Whether choices may be shuffled |
| id | string | Stable question identifier |
| type | string | MVP supports single-choice |
| question | string | Question text |
| choices | array | Choice objects |
| choices[].id | string | Stable choice identifier |
| choices[].text | string | Visible choice text |
| correctChoiceId | string | ID of correct choice |
| explanation | string | Explanation text |
| questionDelayMs | integer | Character/segment print interval |
| choiceDelayMs | integer | Choice print interval |

## 3. Runtime session
```json
{
  "currentQuestionIndex": 0,
  "score": 0,
  "answers": [],
  "status": "playing"
}
```

Answer record:
```json
{
  "questionId": "q001",
  "selectedChoiceId": "a",
  "correct": true,
  "answeredAt": "ISO-8601 timestamp"
}
```

Do not store answer state in the source quiz JSON. Runtime timestamps are generated by the application.

## 4. GS asset manifest
Initial logical states:
- `roll-only`
- `paper-short`
- `paper-medium`
- `paper-full`

Preferred web asset format is selected after testing engine support and mobile performance. Keep source assets and conversion instructions documented. Use consistent origin, scale, orientation and camera framing.

## 5. Validation
- quizId and title are non-empty strings.
- version is a supported positive integer.
- questions contains at least one question.
- question IDs are unique.
- each question has at least two choices.
- choice IDs are unique within a question.
- correctChoiceId matches an existing choice.
- type is `single-choice` in MVP.
- print delays are non-negative integers.
- questionCount does not exceed available questions.
